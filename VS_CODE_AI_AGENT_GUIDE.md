# VS Code AI Agent Guide

## Purpose
Use AI coding agents to accelerate development while focusing on CI/CD learning.

## Recommended Tools
- GitHub Copilot
- GitHub Copilot Chat
- Continue.dev
- Cursor AI

## Recommended Extensions
- Docker
- Kubernetes
- YAML
- SonarLint
- Gradle Extension Pack

## AI Usage Strategy
Use AI for:
- boilerplate code
- Dockerfiles
- Kubernetes YAML
- GitHub Actions
- test generation

Focus personally on:
- architecture
- CI/CD
- debugging
- Kubernetes
- deployment understanding

## Recommended Workflow
1. Define requirement
2. Ask AI to scaffold
3. Review generated code
4. Refactor manually
5. Build CI/CD around it
6. Debug failures

## Suggested Prompt
"Generate reusable FixedWidthFormatter using SOLID principles with truncation and padding support."

## Best Practice
Treat AI as:
- pair programmer
- DevOps helper
- architect assistant

Not as complete replacement engineer.
